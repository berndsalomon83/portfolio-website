01 About

AI is a lever. It pays off when you know what lies beneath.

Hej! I'm Bernd, a senior developer and solution architect living in Sweden. For more than twenty years I built and ran large data platforms and business applications inside the Deutsche Bahn group, owning everything from requirements and architecture decisions to implementation and day-to-day production.

I work spec-driven, with security by design, tests first and decisions written down. I bring the same discipline to AI: I steer it deliberately instead of letting it run blind. To develop and test LLM solutions I run my own NVIDIA DGX Spark, private inference that doesn't depend on anyone's cloud API.
